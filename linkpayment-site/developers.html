API 연동 매뉴얼

링크페이먼트 신용카드 결제창을 가맹점 웹사이트에 연동하는 방법을 안내합니다.

대상
신용카드 결제창(인증·비인증)
문서 기준
2026.09.09 샘플 코드
기술 문의 가맹점 관리자 (새 창)

목차

연동 개요

가맹점 결제 페이지에 링크페이먼트 결제 스크립트를 추가하고, 결제창을 호출한 뒤 결과를 받아 처리합니다.

결제키는 계약 후 발급됩니다 가맹점 ID와 결제키(publicKey)는 영업 담당자와 계약한 뒤 발급받습니다. 사용하는 결제키에 따라 실결제와 테스트 결제가 구분되니, 테스트할 때 어떤 키를 쓰는지 꼭 확인하세요.
구분호출주소상태
망 테스트echoPOST https://api.linkpayment.co.kr/api/echo제공
인증결제paynix.pay · payRoute: '3ds'https://api.linkpayment.co.kr/api/pay제공
비인증결제paynix.pay · payRoute: 'regular'https://api.linkpayment.co.kr/api/pay사전 승인 필요
결제 취소refundhttps://api.linkpayment.co.kr/api/refund준비 중
결과 조회gethttps://api.linkpayment.co.kr/api/get준비 중
영수증--준비 중

결제 흐름

가맹점, 링크페이먼트(PG), 카드사 사이에서 인증과 승인이 차례로 진행됩니다.

  1. 1가맹점

    결제창 호출

    결제 페이지에서 clientside.js의 paynix.pay로 결제창을 엽니다.

  2. 2PG · 카드사

    카드 인증

    구매자가 카드 인증(MPI/ISP)을 진행합니다. 비인증결제는 이 단계가 없습니다.

  3. 3PG · 카드사

    승인

    링크페이먼트가 카드사에 승인을 요청하고 결과를 받습니다.

  4. 4가맹점

    결과 처리

    결과를 responseFunction 또는 webhookUrl로 받아 완료·실패 화면을 보여줍니다.

빠른 시작

  1. 1
    결제키 발급계약 후 결제키(publicKey, pk_로 시작)와 결제 방식(payRoute)을 안내받습니다.
  2. 2
    망 테스트echo API로 결제키와 연결 상태를 확인합니다.
  3. 3
    결제창 연동결제 페이지에 스크립트를 추가하고 paynix.pay를 호출합니다.
  4. 4
    결과 처리결과 코드를 확인하고, 승인 정보를 가맹점 서버에 저장하는 처리를 구현합니다.
  5. 5
    테스트 후 운영 전환테스트 결제로 전체 흐름을 확인한 뒤 운영 결제키로 바꿉니다.

망 테스트 (echo)

결제키로 링크페이먼트 API에 연결되는지 확인합니다. 결제키는 Authorization 헤더에 담아 보냅니다.

헤더값
Content-Typeapplication/json
Acceptapplication/json
Authorization발급받은 결제키 (pk_로 시작)
cURL
curl -X POST https://api.linkpayment.co.kr/api/echo \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "Authorization: pk_발급받은_결제키" \
  -d '{}'
JavaScript
fetch('https://api.linkpayment.co.kr/api/echo', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Accept': 'application/json',
    'Authorization': 'pk_발급받은_결제키'
  },
  body: JSON.stringify({})
})
  .then(function (res) { return res.json(); })
  .then(function (data) { console.log(data); });

결제 요청

결제 페이지에 결제 스크립트를 추가하고, 결제 버튼을 눌렀을 때 paynix.pay를 호출합니다. 결제창은 레이어 형태로 열립니다.

HTML · 스크립트 추가
<script src="https://api.linkpayment.co.kr/js/clientside.js"></script>
JavaScript · 결제창 호출
var products = [
  { name: '상품명', price: '1004', qty: '1', desc: '상품 설명' }
];

paynix.pay({
  publicKey: 'pk_발급받은_결제키',  // 계약 후 발급
  payRoute: '3ds',                 // 인증결제 '3ds' / 비인증결제 'regular'
  amount: 1004,
  products: products,
  payerName: '홍길동',
  payerEmail: 'buyer@example.com',
  payerTel: '010-0000-0000',
  udf1: '',                        // 가맹점 임의 데이터
  udf2: '',
  responseFunction: handlePaymentResponse,
  webhookUrl: '',                  // 결과를 받을 URL (선택)
  mode: 'layer',                   // 고정값
  debugMode: 'live'                // 고정값
});

결제 결과

responseFunction에는 결과가 JSON 문자열로 전달됩니다. result.resultCd가 0000이면 승인 성공이며, 승인 정보는 성공한 경우에만 담깁니다.

JavaScript · 결과 처리
function handlePaymentResponse(response) {
  var res = JSON.parse(response);

  if (res.result.resultCd === '0000') {
    // 승인 성공: 결과를 가맹점 서버로 보내 주문 상태를 저장합니다. (가맹점 구현)
    saveOrderResult(res);
  } else {
    // 승인 실패: 메시지로 사유를 안내합니다. (가맹점 구현)
    showPaymentFailed(res.result.resultMsg, res.result.advanceMsg);
  }
}

비인증결제

카드 인증 단계 없이 결제하는 방식입니다. 요청 방법은 인증결제와 같고 payRoute만 'regular'로 보냅니다.

비인증결제는 업종 등에 대한 사전 승인이 필요합니다. 이용하려면 먼저 도입 상담을 요청해 주세요.

결제 취소 · 결과 조회

결제 취소(refund), 결과 조회(get), 영수증 API는 준비 중입니다. 공개되면 이 매뉴얼에 추가합니다.
