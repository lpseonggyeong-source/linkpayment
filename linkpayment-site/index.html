판매 방식별 결제

어떻게 결제를
받으시나요?

판매 방식을 고르면 맞는 결제 서비스와 도입 방법을 안내합니다.

  1. 01.

    • 카드결제
    • 간편결제
    • 가상계좌

    온라인 쇼핑몰에서 고객이 원하는 결제수단으로 주문을 마칩니다. 결제수단별 이용 흐름을 비교하고 도입 절차를 확인하세요.

    자세히 보기
  2. 02.

    • SMS 결제
    • URL 결제
    • 수기결제

    결제 링크를 문자로 보내거나 메시지로 공유하면, 고객이 링크를 열어 바로 결제합니다.

    자세히 보기
  3. 03.

    • 스포츠노트
    • 테이블오더
    • 스마트오더
    • 키오스크

    도장 출결 문자를 무료로 보내는 스포츠노트(구 케어아이)부터 테이블 주문, 무인 주문까지 업종에 맞는 운영 솔루션을 살펴보세요.

    자세히 보기
  4. 04.

    • LinkU

    LinkU에 상품을 등록하고 판매 링크를 공유하면, 구매자가 링크에서 상품을 확인하고 결제합니다.
